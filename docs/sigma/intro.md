# SIGMA - Sistema Integral de Gestión y Análisis Electoral

Bienvenido a la documentación de **SIGMA**, un sistema completo para la gestión y análisis de procesos electorales.

## 🎯 Descripción

SIGMA es una plataforma diseñada para centralizar y optimizar la gestión de información electoral, permitiendo un control eficiente de votantes, campañas y resultados.
